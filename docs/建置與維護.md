# 建置與維護

## 系統程式設計邏輯

Google Earth 圖資檔案以 .kml 方式匯入，地圖採圖層分離，方便個別項目編輯以及檢視。
底圖使用「Google 我的地圖」多邊形工具劃設並編號商圈後輸出為 .kml 檔，再匯入 Google Earth 作為商耕底圖。

商耕底圖為 `商圈最新版.kml`，動態圖資為另一個檔案 `live_map.kml`。KML 檔皆可用 Notepad++ 開啟編輯。
系統大致分為三區塊：

1. `live_map.kml`：圖資資訊設定，抓取 Google 試算表 Apps Script 網址，更新頻率設定為每分鐘。
2. Apps Script：透過圖資系統在各商圈建立隱形的地標（以經緯度座標為界線計算），取其中心點展示資料表資訊。
3. Google Earth：分別匯入商耕底圖與動態圖資為兩個獨立圖層。

---

## 一、建立 Apps Script 網路應用程式

1. 由試算表「擴充功能 → Apps Script」進入編輯頁面，貼上 `apps-script/Code.gs`。
2. 執行一次，確認執行完畢無報錯。
3. 點擊右上「部署 → 新增部署作業 → 網頁應用程式」。
   - 執行身分：我（部署者本人）
   - 具有存取權的使用者：**任何人**（Google Earth 以匿名身分抓取，此項不可設為僅限自己）
4. 部署後會生成一組網頁應用程式網址，點擊複製備用。

## 二、建立動態圖資 KML 檔案

建立文字文件並輸入 `kml/live_map.kml` 的內容，其中 `<href>` 填入上一步部署所生成的
網頁應用程式網址，儲存後確認副檔名為 `.kml`。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<kml xmlns="http://www.opengis.net/kml/2.2">
  <NetworkLink>
    <name>商圈即時動態標籤</name>
    <Link>
      <href>https://script.google.com/macros/s/.../exec</href>
      <refreshMode>onInterval</refreshMode>
      <refreshInterval>60</refreshInterval>
    </Link>
  </NetworkLink>
</kml>
```

## 三、Google Earth 匯入圖資

「檔案 → 匯入檔案（KML/Z, GeoJSON, GLB, SHP…）→ 從裝置上傳」，
選擇 `商圈最新版.kml` 及 `live_map.kml`，完成後即成功建立左列圖層。

## 維護與管理

### 更新 Apps Script 版本

1. 新增部署後，到 Apps Script「管理部署作業」頁面將**舊版本封存**，再行部署新版本。
2. 部署完成後，修改 `live_map.kml` 中的 `<href>` 為新部署產生的網頁應用程式網址。
3. 刪除 Google Earth 中的舊圖層（「顯示資訊」圖層），再重新匯入 `live_map.kml`。

### 更改商圈範圍 / 製作其他區域商耕圖

須將輸出之 .kml 檔提取經緯度座標，轉為 WKT 格式後置於試算表 A 欄，其餘步驟相同。

轉換可用本倉庫的工具：

```bash
python3 tools/kml_to_wkt.py data/商圈最新版.kml -o 商圈WKT.csv
```

產生的 CSV 有 `WKT`、`Sequence_ID` 兩欄，直接貼到試算表 A、B 欄即可。

#### 核心原理：KML 與 WKT 的格式差異

- **KML 檔內的原始座標（XML 標籤）**：以逗號分隔經緯度、以空白分隔點

  ```xml
  <coordinates>121.531,25.041,0 121.532,25.042,0 121.531,25.041,0</coordinates>
  ```

- **WKT (Well-Known Text) 格式**：以空白分隔經緯度、以逗號分隔點

  ```
  POLYGON ((121.531 25.041, 121.532 25.042, 121.531 25.041))
  ```
